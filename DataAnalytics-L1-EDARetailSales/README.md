# EDA Retail Sales Analysis

Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data using Python. The objective is to identify sales trends, customer demographics, product performance, and relationships between numerical variables.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Analysis Performed

- Data loading and initial inspection
- Data cleaning and preprocessing
- Descriptive statistics
- Monthly sales trend analysis
- Quarterly sales trend analysis
- Customer age group analysis
- Customer gender analysis
- Top 10 best-selling products
- Revenue analysis
- Correlation heatmap
- Additional customer analysis

 Key Insights

The analysis identifies important patterns in sales, customer demographics, and product performance. These insights can help businesses understand their customers and improve sales and marketing strategies.

 Business Recommendations

1. Focus marketing campaigns on the largest customer age groups.
2. Maintain sufficient inventory for the best-selling products.
3. Use monthly and quarterly sales trends for better inventory and promotional planning.
4. Develop targeted strategies for high-value customers.
